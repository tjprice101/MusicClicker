                GUIDE: ADDING NEW SCORES (MINOR AND MAJOR) TO MUSICCLICKER
═══════════════════════════════════════════════════════════════════════════════

This comprehensive guide covers everything needed to add a new score family to
the game, including minor fragments, major fragments, and score crafting.

═══════════════════════════════════════════════════════════════════════════════
UNDERSTANDING THE SCORE SYSTEM
═══════════════════════════════════════════════════════════════════════════════

TERMINOLOGY REFRESHER:
- FRAGMENTS:    Raw materials collected from clicking/upgrades
- MINOR SCORE:  Craftable item made from minor fragments (3 types: Keys, Scales, Progressions)
- MAJOR SCORE:  Craftable item made from major fragments (3 types: Keys, Scales, Progressions + Major Sheets)
- SCORE FAMILY: A collection of related scores (e.g., Moonlight, Eroica, Swan Lake)

FRAGMENT FLOW:
1. Player collects fragments (minor/major keys, scales, progressions)
2. Fragments are spent to craft scores in "Save Scores" screen
3. Crafted scores are used in "Unite the Symphony" screen
4. Major scores unlock weapons and special abilities

STEP 1: PLAN YOUR SCORE FAMILY
═══════════════════════════════════════════════════════════════════════════════

Before coding, decide on:

1. SCORE BASICS
   - Family Name:     e.g., "Requiem"
   - Theme:           Musical style or concept
   - Unlock Tier:     Early, mid, or late game?
   - Fragment Colors: For UI differentiation

2. MINOR SCORE COSTS
   Standard pattern (adjust as needed):
   - Keys Cost:        10 minor keys
   - Scales Cost:      5 minor scales
   - Progressions Cost: 3 minor progressions

3. MAJOR SCORE COSTS
   Standard pattern (adjust as needed):
   - Keys Cost:        20 major keys
   - Scales Cost:      10 major scales
   - Progressions Cost: 5 major progressions
   - Sheets Cost:      1 major sheet (unlocked via special method)

4. ASSOCIATED WEAPONS
   - How many weapons in this family? (typically 2-3)
   - What are their abilities?
   - Do they form a duet?

   /// <summary>
   /// Crafts a Requiem Minor Score using collected minor fragments.
   /// </summary>
   public static void CraftRequiemMinor(GameState gs)
   {
       // Define costs
       int keyCost = 10;
       int scaleCost = 5;
       int progressionCost = 3;
       
       // Check if player has enough fragments
       if (gs.RequiemMinorKeys < keyCost)
       {
           Console.WriteLine("Not enough Requiem Minor Keys!");
           return;
       }
       if (gs.RequiemMinorScales < scaleCost)
       {
           Console.WriteLine("Not enough Requiem Minor Scales!");
           return;
       }
       if (gs.RequiemMinorProgressions < progressionCost)
       {
           Console.WriteLine("Not enough Requiem Minor Progressions!");
           return;
       }
       
       // Deduct fragments
       gs.RequiemMinorKeys -= keyCost;
       gs.RequiemMinorScales -= scaleCost;
       gs.RequiemMinorProgressions -= progressionCost;
       
       // Award crafted score
       gs.RequiemMinorOwned++;
       
       Console.WriteLine($"Crafted Requiem Minor Score! Total owned: {gs.RequiemMinorOwned}");
   }
   ```

2. IMPLEMENT CRAFT FUNCTION

   /// <summary>
   /// Crafts a Requiem Major Score using collected major fragments.
   /// </summary>
   public static void CraftRequiemMajor(GameState gs)
   {
       // Define costs
       int keyCost = 20;
       int scaleCost = 10;
       int progressionCost = 5;
       int sheetCost = 1;
       
       // Check fragments
       if (gs.RequiemMajorKeys < keyCost ||
           gs.RequiemMajorScales < scaleCost ||
           gs.RequiemMajorProgressions < progressionCost ||
           gs.RequiemMajorSheets < sheetCost)
       {
           Console.WriteLine("Not enough major fragments!");
           return;
       }
       
       // Deduct fragments
       gs.RequiemMajorKeys -= keyCost;
       gs.RequiemMajorScales -= scaleCost;
       gs.RequiemMajorProgressions -= progressionCost;
       gs.RequiemMajorSheets -= sheetCost;
       
       // Award score
       gs.RequiemMajorOwned++;
       
       // Unlock ability on first craft
       if (gs.RequiemMajorOwned == 1)
       {
           gs.RequiemMajorAbility = true;
           Console.WriteLine("Unlocked Requiem Major Ability!");
       }
       
       Console.WriteLine($"Crafted Requiem Major Score! Total owned: {gs.RequiemMajorOwned}");
   }
   ```

STEP 9: ADD MAJOR SHEET UNLOCK MECHANISM
═══════════════════════════════════════════════════════════════════════════════

Major Sheets are special and should be unlocked through significant milestones.

OPTION 1: UNLOCK VIA MILESTONE
```csharp
// When player reaches certain threshold
if (gs.RequiemMajorOwned >= 10 && gs.RequiemMajorSheets == 0)
{
    gs.RequiemMajorSheets = 1;
    Console.WriteLine("Unlocked Requiem Major Sheet!");
}
```

OPTION 2: UNLOCK VIA CRAFTING
```csharp
public static void CraftRequiemMinor(GameState gs)
{
    // ... craft logic ...
    
    // Every 5 minor scores grants a major sheet
    if (gs.RequiemMinorOwned % 5 == 0)
    {
        gs.RequiemMajorSheets++;
        Console.WriteLine("Awarded Requiem Major Sheet!");
    }
}
```

OPTION 3: UNLOCK VIA FRAGMENTS
```csharp
// Trade minor fragments for major sheet
public static void ConvertToRequiemMajorSheet(GameState gs)
{
    int keyCost = 100;
    int scaleCost = 50;
    int progressionCost = 25;
    
    if (gs.RequiemMinorKeys >= keyCost &&
        gs.RequiemMinorScales >= scaleCost &&
        gs.RequiemMinorProgressions >= progressionCost)
    {
        gs.RequiemMinorKeys -= keyCost;
        gs.RequiemMinorScales -= scaleCost;
        gs.RequiemMinorProgressions -= progressionCost;
        gs.RequiemMajorSheets++;
        
        Console.WriteLine("Converted fragments to Requiem Major Sheet!");
    }
}
```

   /// <summary>
   /// Requiem Major Ability: Grants +5% NPS per major score owned
   /// </summary>
   public static double RequiemMajor_GetNpsMultiplier(GameState gs)
   {
       if (!gs.RequiemMajorAbility)
           return 1.0; // Ability not unlocked
       
       // +5% per major score owned
       double bonus = 1.0 + (gs.RequiemMajorOwned * 0.05);
       return bonus;
   }
