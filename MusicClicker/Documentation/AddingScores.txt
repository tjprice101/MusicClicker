═══════════════════════════════════════════════════════════════════════════════
                GUIDE: ADDING NEW SCORES (MINOR AND MAJOR) TO MUSICCLICKER
═══════════════════════════════════════════════════════════════════════════════

This comprehensive guide covers everything needed to add a new score family to
the game, including minor fragments, major fragments, and score crafting.

═══════════════════════════════════════════════════════════════════════════════
UNDERSTANDING THE SCORE SYSTEM
═══════════════════════════════════════════════════════════════════════════════

TERMINOLOGY REFRESHER:
- MINOR FRAGMENTS: Crafting components (Minor Keys, Minor Scales, Minor Progressions)
- MAJOR SHEETS:    Special items that unlock major crafting components
- MAJOR FRAGMENTS: Crafting components obtained from Major Sheets (Major Keys, Major Scales, Major Progressions)
- MINOR SCORE:     Craftable item made from minor fragments
- MAJOR SCORE:     Craftable item made from major fragments (requires Major Sheet to unlock components)
- SCORE FAMILY:    A collection of related scores (e.g., Moonlight, Eroica, Swan Lake)

CRAFTING FLOW:
1. Player collects MINOR FRAGMENTS (keys, scales, progressions) from clicking/upgrades
2. Minor fragments are spent to craft MINOR SCORES in "Save Scores" screen
3. Player obtains MAJOR SHEETS (from milestones or special methods)
4. Major Sheets unlock the ability to collect MAJOR FRAGMENTS (major keys, scales, progressions)
5. Major fragments are spent to craft MAJOR SCORES in "Heart of Harmony" screen
6. Crafted scores are used in "Unite the Symphony" screen
7. Major scores unlock weapons and special abilities

4. ASSOCIATED WEAPONS
   - How many weapons in this family? (typically 2-3)
   - What are their abilities?
   - Do they form a duet?

   ```csharp
   /// <summary>
   /// Crafts a Requiem Minor Score using collected minor fragments.
   /// </summary>
   public static void CraftRequiemMinor(GameState gs)
   {
       // Define costs
       int keyCost = 10;
       int scaleCost = 5;
       int progressionCost = 3;
       
       // Check if player has enough fragments
       if (gs.RequiemMinorKeys < keyCost)
       {
           Console.WriteLine("Not enough Requiem Minor Keys!");
           return;
       }
       if (gs.RequiemMinorScales < scaleCost)
       {
           Console.WriteLine("Not enough Requiem Minor Scales!");
           return;
       }
       if (gs.RequiemMinorProgressions < progressionCost)
       {
           Console.WriteLine("Not enough Requiem Minor Progressions!");
           return;
       }
       
       // Deduct fragments
       gs.RequiemMinorKeys -= keyCost;
       gs.RequiemMinorScales -= scaleCost;
       gs.RequiemMinorProgressions -= progressionCost;
       
       // Award crafted score
       gs.RequiemMinorOwned++;
       
       Console.WriteLine($"Crafted Requiem Minor Score! Total owned: {gs.RequiemMinorOwned}");
   }
   ```

   ```csharp
   /// <summary>
   /// Crafts a Requiem Major Score using collected major fragments.
   /// Note: Major fragments (keys, scales, progressions) are obtained by using Major Sheets.
   /// </summary>
   public static void CraftRequiemMajor(GameState gs)
   {
       // Define costs
       int keyCost = 20;
       int scaleCost = 10;
       int progressionCost = 5;
       
       // Check fragments
       if (gs.RequiemMajorKeys < keyCost ||
           gs.RequiemMajorScales < scaleCost ||
           gs.RequiemMajorProgressions < progressionCost)
       {
           Console.WriteLine("Not enough major fragments!");
           return;
       }
       
       // Deduct fragments
       gs.RequiemMajorKeys -= keyCost;
       gs.RequiemMajorScales -= scaleCost;
       gs.RequiemMajorProgressions -= progressionCost;
       
       // Award score
       gs.RequiemMajorOwned++;
       
       // Unlock ability on first craft
       if (gs.RequiemMajorOwned == 1)
       {
           gs.RequiemMajorAbility = true;
           Console.WriteLine("Unlocked Requiem Major Ability!");
       }
       
       Console.WriteLine($"Crafted Requiem Major Score! Total owned: {gs.RequiemMajorOwned}");
   }
   ```

STEP 9: ADD MAJOR SHEET SYSTEM
═══════════════════════════════════════════════════════════════════════════════

Major Sheets are special items that UNLOCK the ability to obtain major fragments.
Players use/convert Major Sheets to get major keys, scales, and progressions.

OPTION 1: DIRECT CONVERSION (1 SHEET → MAJOR FRAGMENTS)
```csharp
// Player spends 1 Major Sheet to get major fragments
public static void ConvertRequiemMajorSheet(GameState gs)
{
    if (gs.RequiemMajorSheets < 1)
    {
        Console.WriteLine("No Major Sheets available!");
        return;
    }
    
    // Deduct sheet
    gs.RequiemMajorSheets--;
    
    // Award major fragments
    gs.RequiemMajorKeys += 5;      // Example: 5 keys per sheet
    gs.RequiemMajorScales += 3;    // Example: 3 scales per sheet
    gs.RequiemMajorProgressions += 1; // Example: 1 progression per sheet
    
    Console.WriteLine("Converted Major Sheet to major fragments!");
}
```

OPTION 2: UNLOCK MAJOR FRAGMENT DROPS (SHEET UNLOCKS COLLECTION)
```csharp
// First Major Sheet unlocks the ability to collect major fragments
public static void UnlockRequiemMajorFragments(GameState gs)
{
    if (gs.RequiemMajorSheets >= 1)
    {
        // Once player has ANY major sheet, they can collect major fragments
        // from clicks, upgrades, etc.
        // Major Sheets then become currency for other purposes
    }
}
```

OPTION 3: AWARD MAJOR SHEETS FROM MILESTONES
```csharp
public static void CraftRequiemMinor(GameState gs)
{
    // ... craft logic ...
    
    // Every 5 minor scores grants a major sheet
    if (gs.RequiemMinorOwned % 5 == 0)
    {
        gs.RequiemMajorSheets++;
        Console.WriteLine("Awarded Requiem Major Sheet for milestone!");
    }
}
```

RECOMMENDED APPROACH:
Use Major Sheets as a conversion currency. Players earn Major Sheets from milestones,
then use them in the Heart of Harmony screen to convert to major fragments.

   ```csharp
   /// <summary>
   /// Requiem Major Ability: Grants +5% NPS per major score owned
   /// </summary>
   public static double RequiemMajor_GetNpsMultiplier(GameState gs)
   {
       if (!gs.RequiemMajorAbility)
           return 1.0; // Ability not unlocked
       
       // +5% per major score owned
       double bonus = 1.0 + (gs.RequiemMajorOwned * 0.05);
       return bonus;
   }
   ```
