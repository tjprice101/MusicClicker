═══════════════════════════════════════════════════════════════════════════════
                    GUIDE: ADDING NEW WEAPONS TO MUSICCLICKER
═══════════════════════════════════════════════════════════════════════════════

This comprehensive guide walks you through every step of adding a new weapon to
the game, including solo weapons, duet pairs, and their associated abilities.

═══════════════════════════════════════════════════════════════════════════════
STEP 1: PLAN YOUR WEAPON
═══════════════════════════════════════════════════════════════════════════════

Before coding, decide on the following:

1. WEAPON BASICS
   - Name:           e.g., "Requiem's Edge"
   - Internal ID:    e.g., "RequiemsEdge" (no spaces, PascalCase)
   - Associated Score: Which score unlocks it? (e.g., Moonlight, Eroica)
   - Rarity Tier:    Minor or Major score weapon?

2. WEAPON ABILITY (PASSIVE)
   - Effect Type:    NPS multiplier? Click bonus? Special mechanic?
   - Balance:        How powerful should it be?
   - Conditions:     Always active? Conditional?
   
   EXAMPLES:
   - "Doubles NPS when equipped"
   - "Adds 50% click power when resonated"
   - "Grants +10% NPS per major score owned"

3. DUET ABILITY (IF APPLICABLE)
   - Partner Weapon: Which weapon does it pair with?
   - Duet Name:      e.g., "Eclipse Duet"
   - Duet Effect:    Passive or active ability?
   - Cooldown:       If active, what cooldown duration?
   
   EXAMPLES:
   - Passive: "Triple NPS when both weapons equipped"
   - Active: "10-second ability with 30-minute cooldown"

2. CREATE UPDATE METHOD
   Add a new method to update the weapon's UI based on ownership:
   
   ```csharp
   private void UpdateRequiemsEdgeUI(GameState gs)
   {
       if (RequiemsEdgeBorder == null) return;
       
       if (gs.RequiemsEdge)
       {
           RequiemsEdgeBorder.Opacity = 1.0;
           RequiemsEdgeStatus.Text = "Status: Unlocked";
           RequiemsEdgeStatus.Foreground = new SolidColorBrush(Colors.LimeGreen);
       }
       else
       {
           RequiemsEdgeBorder.Opacity = 0.5;
           RequiemsEdgeStatus.Text = "Status: Locked";
           RequiemsEdgeStatus.Foreground = new SolidColorBrush(Colors.Gray);
       }
   }
   ```

3. ADD TO REFRESH METHOD
   Find the `Refresh()` method and add your update call:
   
   ```csharp
   public void Refresh()
   {
       var window = MainWindow.FindMainWindow(this);
       if (window?.GameState == null) return;
       
       // ... existing updates ...
       UpdateRequiemsEdgeUI(window.GameState);
   }
   ```

STEP 7: IMPLEMENT PASSIVE ABILITY
═══════════════════════════════════════════════════════════════════════════════

📄 File: Game Logic/Systems/WeaponAbilities.cs

1. ADD ABILITY FUNCTION
   Create a new static method:
   
   ```csharp
   /// <summary>
   /// Requiem's Edge passive: Doubles NPS when equipped
   /// </summary>
   public static double RequiemsEdge_GetNpsMultiplier(GameState gs)
   {
       // Check if weapon is equipped in either slot
       if (gs.CurrentResonatedWeapon1 == "RequiemsEdge" || 
           gs.CurrentResonatedWeapon2 == "RequiemsEdge")
       {
           return 2.0; // 2x multiplier
       }
       return 1.0; // No effect
   }
   ```

2. INTEGRATE INTO GAME LOOP
   📄 File: MainWindow.axaml.cs
   
   Find the background NPS timer (around line 400-500) and add:
   
   ```csharp
   // Background NPS accumulation
   _backgroundNpsTimer.Elapsed += (s, e) =>
   {
       double effectiveNps = gameState.NotesPerSecond;
       
       // ... existing multipliers ...
       
       // Apply Requiem's Edge passive
       effectiveNps *= MusicClicker.Armory.WeaponAbilities.RequiemsEdge_GetNpsMultiplier(gameState);
       
       // Accumulate notes
       MusicClicker.Helpers.AtomicDouble.Add(ref gameState._notes, effectiveNps * elapsed);
   };
   ```

📄 File: Game Logic/Systems/WeaponAbilities.cs

3. IMPLEMENT DUET EFFECT
   
   FOR PASSIVE DUET:
   ```csharp
   public static double EclipseDuet_GetNpsMultiplier(GameState gs)
   {
       if ((gs.CurrentResonatedWeapon1 == "RequiemsEdge" && gs.CurrentResonatedWeapon2 == "PartnerWeapon") ||
           (gs.CurrentResonatedWeapon1 == "PartnerWeapon" && gs.CurrentResonatedWeapon2 == "RequiemsEdge"))
       {
           return 3.0; // Triple NPS
       }
       return 1.0;
   }
   ```
   
   FOR ACTIVE DUET:
   ```csharp
   public static void EclipseDuet_Activate(GameState gs)
   {
       // Check cooldown (30 minutes = 1800 seconds)
       if ((DateTime.Now - gs.EclipseDuetLastUsed).TotalSeconds < 1800)
           return; // Still on cooldown
       
       // Activate ability
       gs.EclipseDuetActive = true;
       gs.EclipseDuetExpiry = DateTime.Now.AddSeconds(10); // 10 second duration
       gs.EclipseDuetLastUsed = DateTime.Now;
       
       Console.WriteLine("Eclipse Duet activated!");
   }
   
   public static void EclipseDuet_Tick(GameState gs)
   {
       // Check if effect should expire
       if (gs.EclipseDuetActive && DateTime.Now > gs.EclipseDuetExpiry)
       {
           gs.EclipseDuetActive = false;
           Console.WriteLine("Eclipse Duet expired.");
       }
   }
   ```

STEP 10: TEST YOUR WEAPON
═══════════════════════════════════════════════════════════════════════════════

TESTING CHECKLIST:

□ Weapon appears in Armory screen (locked initially)
□ Weapon unlocks after meeting condition (craft score, collect fragments, etc.)
□ Weapon appears in Tempo Resonate screen after unlock
□ Weapon can be equipped in Slot 1
□ Weapon can be equipped in Slot 2
□ Passive ability works correctly when equipped
□ Passive ability stops when unequipped
□ Duet detection works (if applicable)
□ Duet ability activates (if applicable)
□ Cooldown timer works correctly (if applicable)
□ Weapon persists after save/load
□ No crashes or errors in console

═══════════════════════════════════════════════════════════════════════════════
STEP 11: BALANCE TESTING
═══════════════════════════════════════════════════════════════════════════════

After implementation, test for game balance:

1. NPS IMPACT
   - Compare NPS before and after equipping
   - Ensure multiplier is not too strong/weak for its unlock tier
   - Test with multiple upgrades owned

2. CLICK IMPACT (if applicable)
   - Test click power scaling
   - Ensure it doesn't trivialize progression

3. DUET BALANCE (if applicable)
   - Active ability should feel impactful but not mandatory
   - Cooldown should be long enough to prevent spam
   - Duration should be satisfying but not overwhelming

4. PROGRESSION PACING
   - Weapon should unlock at appropriate time in player journey
   - Should provide meaningful power increase
   - Should not invalidate existing strategies

COMMON PITFALLS TO AVOID
═══════════════════════════════════════════════════════════════════════════════

❌ MISTAKE: Forgetting to add weapon to GameState
   → RESULT: Weapon doesn't persist after save/load

❌ MISTAKE: Not updating both weapon slots
   → RESULT: Weapon only works in one slot

❌ MISTAKE: Hardcoding weapon checks everywhere
   → FIX: Use DuetAbilityDetector for all duet checks

❌ MISTAKE: Not testing with existing weapons equipped
   → RESULT: Conflicts or unexpected interactions

❌ MISTAKE: Forgetting to update UIUpdater
   → RESULT: UI doesn't reflect weapon effects

❌ MISTAKE: Making passive abilities too powerful
   → FIX: Balance against existing weapons in same tier
