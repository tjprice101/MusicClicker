1. NEW UI LAYOUT STRUCTURE
================================================================================

Grid-Based 4-Row Layout:
  Row 0 (80px):   Header with gold border and title "⚡ TEMPO RESONATE ⚡"
  Row 1 (*):      Main Content - 3-column layout (Scores | Equipment | Weapons)
  Row 2 (Auto):   Crescendance Info Panel (compact, integrated)
  Row 3 (70px):   Bottom Navigation (Back button)

Main Content - 3 Columns:
  Left (340px):   Major Scores drawer
                  - Blue theme (#DD1A1A2E background, #4466AAFF border)
                  - "📜 MAJOR SCORES" header
                  - ScrollViewer for score list
                  
  Center (*):     Equipment Display
                  - Larger score card display (Grid.Row height="2*")
                  - Dual weapon slots (Grid.Row height="1.2*" each)
                  - Equipment prompt at top (green YES/red NO buttons)
                  - Click-to-unequip hints on equipped items
                  
  Right (340px):  Weapons drawer (Armory of Forte)
                  - Orange theme (#DD2E1A1A background, #FFAA44 border)
                  - "⚔️ ARMORY OF FORTE" header
                  - ScrollViewer for weapon list

================================================================================
3. TOOLTIP SYSTEM
================================================================================

New Components:
  - DescriptionTooltipPanel (Border, ZIndex="1000")
  - TooltipTitle (TextBlock, 18pt bold)
  - TooltipDescription (TextBlock, 14pt in ScrollViewer)
  - Positioned at center of screen, above all other elements
  - MaxWidth="450", MaxHeight="300" for readability

Implementation Files:
  - TempoResonateDescriptions.cs: Centralized description database
    * MajorScores class: All 7 major score descriptions
    * Weapons class: All 14 weapon descriptions
    * GetDescription(): Lookup method by item name
    
  - TempoResonateScreen.axaml.cs: Tooltip event handling
    * InitializeTooltips(): Gets panel references, hides on startup
    * AttachTooltipHandlers(): Registers PointerEnter/Exit events
    * ShowTooltip(): Displays description for hovered item
    * HideTooltip(): Hides tooltip panel
    * RegisterTooltipItem(): Public method for manager to register items
    
  - TempoResonateManager.cs: Tooltip registration integration
    * Added _screen field reference
    * Added screen parameter to constructor
    * Calls RegisterTooltipItem() when adding score/weapon buttons
    * Helper methods: ScoreToDisplayName(), WeaponToDisplayName()

Description Format:
  Each description includes:
  - Emoji icon and name
  - "Passive:" section explaining base mechanics
  - "Crescendance:" section (for major scores) explaining special effects
  - "Unlock:" requirements (for major scores)
  - "Nighttime Bonus:" (for Moonlight weapons)
  - "Requires:" prerequisite major score (for all weapons)
