VISUAL ENHANCEMENT GUIDELINES (SIMPLE)
═══════════════════════════════════════════════════════════════════════════════

Color/Border Enhancements:
- Panel borders: 2-3px solid, #AA000000 (subtle black)
- Panel backgrounds: #55000000 (semi-transparent dark)
- Consistent spacing: 12-15px margins between all elements
- Button consistency: Same size within each panel

Layout Best Practices:
- All panels should have CornerRadius="8" for modern look
- Use consistent Padding="12" inside all panels
- Maintain symmetry (left panel width = right panel width)
- Keep vertical spacing uniform (15px between stacked buttons)

Ergonomic Considerations:
- Maximum mouse travel: 200-400px from click button to any feature
- Related buttons grouped together
- Most-used features (click, stats) central and always visible
- Bottom carousel never covered by other UI elements
- Crescendance panel appears only when relevant (doesn't clutter)
